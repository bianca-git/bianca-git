### Formu-Letter — [formu-letter.cc](https://formu-letter.cc)

Mail merge has been broken for decades: static, manual, no audit trail. Formu-Letter is an Office Add-in that fixes that — it lives inside Excel and turns "copy this, paste that, hope nobody notices the typo" into something repeatable and traceable. Published on Microsoft AppSource, actively maintained.
